Ingeniero de Sistemas con experiencia en arquitectura y desarrollo de soluciones backend, web y moviles. Enfoque en calidad de codigo, escalabilidad, buenas practicas de ingenieria y entrega continua.

- Desarrollo de aplicaciones web modernas con arquitecturas escalables y mantenibles.
- Desarrollo de aplicaciones moviles nativas e hibridas con enfoque en experiencia de usuario.
- Implementacion de entornos de despliegue, observabilidad y automatizacion para operacion estable.
